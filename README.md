# Time Series of Hurricane's Effect on Stream Water Concentrations

From Sienko, K.E.

This repository contains all of the data and code used to analyze the effects of Hurricane Hugo's disturbance on stream water concentrations of potassium, nitrate, magnesium, calcium, and ammonium, in Puente Roto Mameyes (PRM) and Bisley Quebradas 1, 2 and 3 (BQ1, BQ2, BQ3). The purpose is to reproduce figure 3 of Schaefer et al.

# 1. Data

The folder `raw_data` contains the relevant raw data from the authors of the paper.

# 2. Data Cleaning
The folder `2_data_cleaning` contains the code that extracts the columns from the raw data files that are necessary for the reproducing process.
